# Instructions du projet

## Livraison sur GitHub

Préférence explicite de Nico, à conserver pour les prochaines sessions :

- Livrer les modifications demandées avec un commit poussé sur GitHub et une
  nouvelle release, sauf instruction explicite contraire.
- Construire et publier les exécutables de release avec les workflows GitHub
  Actions du dépôt, pour Windows, Linux et macOS.
- Suivre les tests, les constructions et la publication jusqu'à leur réussite ;
  corriger les échecs avant de considérer la livraison terminée.
- Conserver les GPX personnels, caches et résultats de vérification hors du dépôt.
- Avancer sans demander de confirmations de routine ; utiliser les instructions
  de la session pour les choix nécessaires.
